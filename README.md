# ♟️ Chess Game

A fully functional browser-based Chess Game built using **HTML**, **CSS**, and **Vanilla JavaScript**. The game follows standard chess rules, including legal move validation, check/checkmate detection, stalemate detection, turn management, and automatic pawn promotion.

---

# For Demo
 https://zeeshan-9109.github.io/Chess/

 ---

## 🚀 Features

- ♟️ Complete 8×8 chess board
- 👑 Standard chess piece movement
- ✅ Legal move validation
- 🔄 Turn-based gameplay
- ⚠️ Check detection
- 🏆 Checkmate detection
- 🤝 Stalemate detection
- 👑 Automatic pawn promotion to Queen
- 🎯 Visual indicators for:
  - Selected piece
  - Legal moves
  - Capture moves
  - King in check
- 🔄 New Game button
- 📱 Responsive design for desktop and mobile
- 🎨 Modern wooden chess board UI

- King safety checks
- Check detection
- Checkmate detection
- Stalemate detection
- Automatic Queen promotion for pawns reaching the last rank
